## 〇、核心结论（5 点）

1. **海外已是半壁江山，且是更赚钱的那一半**。海外收入 2025 年 162.7 亿（占总收入 43.8%），三年从 1% 起步；海外分部利润率 49.2%，已基本追平大陆 50.1%——出海早过了"赔本扩张期"，进入"高利润爆发期"。🟢

2. **东南亚是桥头堡，美洲是最大增量，欧洲刚起步**。亚太（含东南亚）收入 80.1 亿仍是海外第一大区，但美洲单年 +748%（68.1 亿）、欧洲 +506%（14.5 亿）增速更猛。王宁 2025 年 7 月明确："今年北美销售大概率会超越东南亚。" 🟢🟡

3. **IP 集中度反向升高，是海外爆发的双刃剑**。THE MONSTERS（Labubu）2025 年收入 141.6 亿、占总收入 38.1%（2024 还只有 23%），是潮玩史上首个百亿 IP；海外热潮（Lisa/蕾哈娜带货）主要由它驱动。**年报不披露海外分 IP 占比，但 Labubu 在海外的占比大概率高于国内的 38%。** 🟢

4. **泡泡玛特正在用四种方式把"租来的流量"沉淀为"自己的资产"**：**创造**（唱片公司模式签约 200+ 艺术家）→ **使用/变现**（潮玩全品类，毛绒成第一大品类）→ **扩大**（索尼影业电影、popop 珠宝、POP BAKERY 甜品、积木）→ **沉淀**（北京/上海城市乐园、全球巡展、7258 万会员）。这是它从"Funko"走向"迪士尼"的关键跨越。🟢🟡

5. **两个披露盲区需盯**：①海外分国家销售、分 IP 占比年报不披露；②**游戏业务至今无落地产品**（王宁 2023 年提过"乐园、游戏、授权"是衍生方向，但游戏仍是空白）。🟡

# 第三部分：两个披露盲区（需持续盯）

## 盲区一：海外分国家销售、分 IP 占比——年报不披露

泡泡玛特年报**只披露海外分大区**（亚太/美洲/欧洲）的收入与门店，**不披露**：
- 分国家收入（如泰国/美国/日本各多少）——本报告 1.3 节为媒体推算
- **海外分 IP 占比**（如 Labubu 在海外占多少）——这是关键缺口

**合理推断**（非披露）：Labubu 海外占比大概率**高于**国内的 38%——因为海外爆发主要由 Labubu（Lisa/蕾哈娜/Lady Gaga/BTS V 带货）驱动，东南亚尤其如此。🟡

## 盲区二：游戏业务——至今无落地产品

王宁 2023 年泉果对话提到"衍生**乐园、游戏、授权**等多元业务线"，但截至目前：
- **无已发布的自有手游/游戏产品**
- 对比之下，迪士尼/三丽鸥/万代均有游戏衍生收入

游戏是 IP 变现的高毛利长尾渠道，也是泡泡玛特相对迪士尼矩阵的一个明显短板。**这是未来可能的第二曲线触发点，也是当前的空白。** 🟡

# 第四部分：关键观察（给投资判断的锚）

1. **海外已从"故事"变成"事实"**：43.8% 占比 + 49.2% 分部利润率，泡泡玛特已是"总部在中国的全球 IP 公司"。2026 年海外占比破 50% 是里程碑。🟢

2. **海外越成功，Labubu 依赖越深**——这是海外版图的隐藏风险。海外分 IP 占比不披露，是市场最大的信息盲区；**2026 中报（8 月底）若能给出海外 IP 结构，将是重要催化剂。** 🟡

3. **"沉淀 IP"的四大动作（乐园/电影/巡展/会员）决定了它到底是迪士尼还是 Funko**：
   - ✅ 已验证：北京乐园盈利、会员复购 55.7%、海外自有 APP 爆发
   - ⏳ 在路上：上海乐园、索尼电影（早期开发）、POP BAKERY
   - ❌ 空白：游戏业务
   - **判断标准**（引自公众号下篇）：未来 2–3 年，看 THE MONSTERS 占比能否从 38% **主动降到 30% 以下**，同时总收入仍稳健增长——若能，说明第二/第三爆款起来了、渠道与乐园扛住了流量，它正在从"一个爆款的公司"长成"一个 IP 平台"。🟡

4. **估值含义**：当前 162.80 港元 / TTM PE ≈14.6x。海外高利润率（49.2%）若可持续，是支撑当前估值的核心；若 Labubu 退潮 + 海外降速 + 无接棒同时发生，分部利润率会回落。**海外利润率 49.2% 是否为峰值，是 2026 最需验证的数字。** 🟢
