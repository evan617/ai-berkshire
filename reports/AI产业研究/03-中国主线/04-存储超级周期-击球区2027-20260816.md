## 摘要（五条结论）

1. **逻辑链全部验证成立**：AI资本开支（四大云厂2026年合计约7250亿美元，+77%）→ HBM需求激增（三大厂2026年产能全部售罄，已签约事实）→ 产能挤压常规供给 → DRAM合约价2026Q1环比+93~98%（史上最大单季涨幅）→ 原厂利润空前（海力士Q2营业利润率76.3%、三星单季利润超英伟达、美光单季毛利率84.9%）。每个环节都有已落地的商业事件支撑，不是预测。

2. **但周期位置已到繁荣后段**：价格涨幅二阶导已转负（Q1 +95% → Q2 +60% → Q3预测+13~18%）；消费需求被涨价杀死（2026年PC出货预测-10.4%，十年最大跌幅）；下游库存高于正常水位约50%；三星+海力士800万亿韩元扩产、美光2000亿美元建厂已启动，新产能集中在2027H2-2028落地；股价对创纪录利润的反应已转为负面（海力士Q2创纪录利润当天跌9.6%，7月存储板块普遍自高点回撤30~50%）。

3. **估值处于历史最高分位**："预期PE 4-6倍"是周期顶部的经典陷阱（2018年顶部美光静态PE也只有5倍）。看P/B：美光约10倍（GuruFocus口径13.95倍）vs 10年中位数1.93倍；海力士约8倍 vs 上轮周期顶部2.5倍；长鑫科技上市首日+466%后P/B粗估12-16倍。全行业P/B处于100%分位。

4. **历史的判决**："这次不一样（AI改变周期属性）"论点的历史胜率为0/4（1995/2000/2018/2021）。HBM定制化+三寡头格局+长约锁量最多支持"周期变浅"，不支持"周期消失"，而当前价格计价的是后者。存储股稳定赚大钱的唯一买点是行业亏损、减产、P/B约1倍、分析师投降之时（2012-13、2015-16、2019、2022-23，每次持有2-3年回报3~24倍）。

5. **操作结论**：**现价不建议新建仓任何存储原厂股票；持有者应利用长约延续的时间窗口分批兑现**。全产业链商业模式质量最高的是澜起科技（技术垄断、利润不依赖存储价格，★★★★，等估值回落）；A股模组/分销股的数十倍利润增长是库存重估的一次性周期馈赠，用PE估值会犯致命错误。真正的击球区在2027-2028年供给洪峰引发的下一轮行业亏损期。

## 一、存储为什么是AI产业链的"中国机会"——先看逻辑链本身

本轮存储行情的驱动链条五个环节，全部被2025-2026年实证数据确认，且强度超过历史任何一轮：

| 环节 | 实证 | 时点 |
|---|---|---|
| AI资本开支 | Alphabet 2026Q2实际capex 449亿美元（+107%）并上修全年至1950-2050亿美元；四家合计约7250亿美元（+77%） | 2026-07-22财报 |
| HBM产能售罄 | SK海力士CFO确认"2026年HBM供应已全部卖完"；美光确认2025+2026年全部订完；AI需求吸收全球约20%的DRAM晶圆产出 | 已签约事实 |
| 产能挤压 | 原厂产能优先服务器/AI，NAND转企业级SSD，CSP以长约（LTA）锁供给；消费端DDR2古董料都在涨价 | TrendForce 2026-06 |
| 全面涨价 | DRAM合约价：2025Q4 +45~50% → 2026Q1 **+93~98%** → Q2 +58~63% → Q3预测+13~18%；NAND同期+33~38% → +55~60% → +70~75% → +10~15% | TrendForce历季 |
| 原厂利润暴增 | 海力士Q2营业利润60.54万亿韩元（+557%）、利润率76.3%；三星Q2初步营业利润89.4万亿韩元（约19倍，单季超英伟达）；美光FY26Q3营收414.6亿美元（+346%）、毛利率84.9% | 2026-06/07财报 |

**中国的位置有两层**。第一层是标的：A股/港股提供了一批存储产业链公司——接口芯片（澜起）、封测（深科技）、模组（江波龙/佰维）、分销（香农）、利基设计（兆易），以及新上市的中国大陆DRAM原厂长鑫科技（688825）。第二层是变量：长鑫+长存的产能扩张（长鑫2026年底约35万片/月、逼近美光）是原报告认定的三大系统性风险之一——中国供给将首先打崩标准品价格，"对国际三巨头，中国因素意味着顶层生意的溢价更重要、底层生意的均值回归更狠"。这是10年维度最确定的结构判断。

## 二、周期位置：繁荣后段（过热区）的五条证据

1. **价格涨幅二阶导转负**：Q1 +95% → Q2 +60% → Q3预测+13~18%。TrendForce官方措辞："消费端价格承受力已达极限"。
2. **需求破坏已发生**：Gartner预计2026年PC出货量下滑10.4%（十年最大）；PC均价+17%。**8月新增量化证据**：TrendForce（2026-08-10）测算iPhone 18 Pro物料成本因内存涨价上升38%——涨价对消费终端的传导已到旗舰机型层面。
3. **下游囤货**：联想披露内存库存高出正常水位约50%；消费内存Q1价格+110%、SSD+147%引发PC厂囤货竞赛。渠道库存是未来去库存阶段的反噬弹药。
4. **扩产按钮已按下**：三星+海力士800万亿韩元新厂计划（十年1.35千万亿韩元总量）；美光2000亿美元建厂、爱达荷新厂2027年中投产。新产能集中在2027H2-2028落地。**8月新增**：SK海力士（2026-08-07官宣）再投54万亿韩元建龙仁Y2（DRAM，洁净室2029年6月就绪）与清州M17（NAND，洁净室2028年12月就绪）——注意洁净室就绪≠产出放量，这批投资的实质贡献在2028年之后，属于为2030年需求布局。
5. **股价对纪录利润反应为负**：海力士Q2利润创纪录但低于预期，单日跌9.6~13%（2026-07-29）；7月板块自高点回撤30~50%；美光7月曾回落至约9000亿美元后8月又重回万亿（971.66美元，8-14收盘，市值1.10万亿美元）——多空在万亿门口反复拉锯，本身就是晚周期的价格行为。

存储股的估值铁律：**低PE时卖出、高PE（亏损）时买入**。2018年顶部美光静态PE 5倍、华尔街目标价80-100美元，随后股价-57%。当前46位分析师覆盖美光、Strong Buy 40家、0卖出、一致目标价1502美元（stockanalysis，8-14）——与2018年同构。

8月的边际变化值得记录：美光9-22发布FY26Q4财报（Q4指引营收500±10亿美元、EPS约31美元）——若兑现，FY2026全年营收约1290亿美元（FY2025的3.5倍）。创纪录利润与顶部定价的分裂将走到极致，这是验证/证伪"利润顶"的第一个正式时点。

## 四、历史的判决："这次不一样"0胜4负

| 顶部信号 | 2018 | 2021-22 | **2026年7-8月现状** |
|---|---|---|---|
| 分析师一致看多零卖出 | 是（目标价$80-100） | 是 | **是：40买/0卖，目标价隐含+50%** |
| 预期P/E极低 | 约5倍 | 是 | **6-7倍** |
| P/B历史高分位 | 约3倍 | 约2.0-2.1倍 | **10-14倍，超过此前所有顶部数倍** |
| capex/折旧比急升 | 是 | 是 | **约4-5倍** |
| "这次不一样"叙事 | 数据经济 | 云/元宇宙 | **AI/HBM结构性转变** |
| 涨价斜率见顶 | 2018Q3 | 2021Q3 | **正在发生** |

1995、2000、2018、2021四次"周期已死"叙事，需求故事都为真，都没能阻止12-24个月内的崩盘——**需求叙事为真 ≠ 供给纪律为真**，历史上崩盘全部来自供给端。本轮的供给弹药：800万亿韩元级资本开支规划 + 长鑫产能逼近美光 + 2027-28年新厂集中投产。

诚实的半个例外：2013年整合为三寡头后，DRAM底部盈利能力确实系统性抬升（2019年底部美光仍盈利，历史首次），"结构改善"部分兑现——直到2023年被打破。合理先验：**周期仍在，但底部可能比历史更浅；而当前10倍+P/B计价的是"周期消失"**。

唯一稳定赚大钱的买点：行业亏损、减产、P/B约1倍、分析师投降（2012-13、2015-16、2019、2022-23，每次2-3年回报3~24倍）。亏大钱的买点：当下这种位置。

## 五、8月新证据的两面：击球区时点可能比原判断更晚

**原报告（2026-07-30）判断：击球区在2027-2028年供给洪峰。** 8月上半月的新证据对这个判断形成两个方向的拉扯，必须两面呈现：

**支持"供给洪峰在途"的一方（原报告核心证据+8月补充）：**

- TrendForce（2026-07-30）：2027年NAND供给增速将超过需求，NAND sufficiency（自给率指标）2027年转正——**NAND先于DRAM松动**；
- 新产能对2027年当年供给贡献有限：TrendForce口径"新产能实质贡献要到2028年"，但2027H2起陆续投产的产能叠加需求增速回落，供需拐点的方向不变；
- 消费需求破坏在终端量化显形（iPhone 18 Pro BOM +38%，TrendForce 8-10）；
- SK海力士54万亿韩元新厂（8-7官宣）——历史上每一轮周期都死于这一步（顶部利润驱动扩产）。

**支持"2027年仍然偏紧、击球区或推迟至2028"的一方（TrendForce 2026-08-04，原报告未收录）：**

- **DRAM供应2027年全年仍将紧张**，DRAM sufficiency 2026年为-1~-2%（缺口）；
- 2027年HBM位元需求预计+50-60%，仍供不应求；**HBM供应商2027年将保有小幅定价权**；
- 需求侧持续上修：九大CSP 2026年capex 8867亿美元（+90%）、2027年约1.3万亿美元（+50%）（TrendForce 8-3）；
- 连NVIDIA的需求配置变化也是双向的：8-4报道NVIDIA评估将Rubin Ultra的HBM配置从12-Hi HBM4e下调至8-Hi/12-Hi HBM4、SOCAMM容量减半——单机HBM用量有下修迹象，但TrendForce同时判断总位元需求2027年仍+50-60%。

**8月校准后的时点判断**：把两方证据加权，对原报告的修正不是方向性的，而是结构性的——**NAND与DRAM将分道：NAND的过剩与价格压力可能在2027年先行显现（sufficiency转正），DRAM（尤其HBM）的紧张可能延续到2027年全年，全行业供给洪峰与击球区更可能落在2027H2-2028，DRAM侧甚至偏晚**。美光8-4与Sandisk联合发布首个HBF（高带宽闪存）标准，说明原厂已在为"NAND承接AI推理存储需求"铺路——NAND的过剩可能因此被部分对冲，但那是2027年之后的事。

对操作的含义不变、反而更清晰：**现价不建仓的纪律不需要因为"2027年仍紧"而放松——因为击球区买点从来不是"涨价结束"那一刻，而是"行业亏损+减产+P/B回归"那一刻。涨价延续越久，扩产越猛，下一轮亏损越深。** 唯一需要调整的是等待时的跟踪重点：先盯NAND（先行指标），再盯DRAM。

## 本篇要点回顾

1. 逻辑链五环节全部实证成立（capex +77% → HBM售罄 → 产能挤压 → DRAM单季+93~98% → 原厂利润率76-85%），但价格二阶导已转负（Q1+95%→Q3预测+13~18%）、消费需求被杀死（PC出货-10.4%、iPhone 18 Pro BOM+38%）、下游库存高50%、扩产按钮已按下——繁荣后段。
2. 估值判决不变：全行业P/B历史最高分位（美光10-14倍 vs 中位1.93倍），预期PE 4-7倍是周期顶部经典陷阱而非便宜；美光8-14重回万亿、40/46 Strong Buy、0卖出——与2018年顶部同构。
3. 8月两面证据：TrendForce 8-4判断DRAM供应2027年仍紧、HBM供应商2027年保有定价权（对击球区时点的反方证据）；但TrendForce 7-30同时确认NAND sufficiency 2027年转正。校准结论：NAND与DRAM分道，NAND 2027先行松动，全行业击球区落在2027H2-2028、DRAM侧甚至偏晚——**时点或有先后，纪律不变：击球区买点是行业亏损+减产+P/B回归，不是涨价结束**。
4. 标的排序维持：澜起★★★★（商业模式最好、等回40倍）＞三星/深科技/江波龙★★★＞海力士/美光/兆易/佰维/香农★★＞长鑫★（首日+466%双顶陷阱，回撤60%+且良率验证后再评估）。
5. SK海力士8-7再官宣54万亿韩元建厂（洁净室2028年底-2029年中就绪）——顶部利润驱动扩产的剧本继续上演；美光9-22 FY26Q4财报（Q4指引500±10亿美元）是下一个正式验证时点。
